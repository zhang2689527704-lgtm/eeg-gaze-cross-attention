# CausalEEGNet — EEG–gaze temporal predictive alignment

Code, results, and held-out predictions accompanying the manuscript:

> **Temporal Predictive Alignment Between EEG and Eye Movements for Gaze
> Prediction Using Cross-Attention** (IEEE Access, manuscript ID
> Access-2026-39609).

The study evaluates whether 14-channel consumer EEG adds predictive value
beyond gaze history for subsequent gaze changes. Under matched inputs, folds,
and training budgets, the incremental value of EEG beyond gaze history is
small in this structured grid task, while the temporally masked
cross-attention assigns exactly zero attention to prohibited (future)
positions.

**Name note.** The manuscript calls the architecture **CausalEEGNet**. The
code identifier is `TempAlignEEGNet` (the name used during development); the
two refer to the same model. Figure labels use CausalEEGNet.

## Repository layout

| Path | Contents |
|---|---|
| `code/` | Data pipeline, models, baselines, training/evaluation, statistical analysis, figure generation. See `code/README.md`. |
| `results/` | Per-fold/per-seed metrics (`results_main.json`, `results_ablation.json`, `extra_models_cv.json`), the aggregated `summary.json` with confidence intervals and paired tests, mask verification, per-sample attention profiles for Fig. 6, learned-delay/bandwidth training history for Fig. 8, lagged analysis, channel importance, group analysis, training history, the dataset-level statistics (`dataset_stats.json`) used to regenerate demographic macros without the window cache, and the LaTeX macros (`numbers.tex`) used by the manuscript. |
| `predictions/` | Held-out per-window predictions for every model/fold/seed (`.npz`, keys: `targets`, `preds`, `pids`). |
| `figures/` | Final manuscript figures, `Fig1.pdf`–`Fig13.pdf`. |

The window cache (`cache/`) and the BALLADEER dataset are not included; the
cache is regenerated by `code/data_pipeline.py`.

## Reproduction

```bash
# 1. Build the frozen window cache (deterministic)
python code/data_pipeline.py

# 2. Main comparison (nested participant-level 5-fold CV)
python code/run_main.py --models TempAlignEEGNet,GazeOnly,EEGOnly,LSTM,Transformer,LTC,WaveletTransformer
python code/run_main.py --models StatBaselines

# 3. Masked LSTM / Transformer baselines
python code/run_extra_models.py --models MaskedLSTM,MaskedTransformer --seeds 42,43,44

# 4. Ablations and controls
python code/run_ablations.py --variants NoMask,FrontalExcluded,TempStructNet,PermutedTarget --seeds 42,43,44
python code/run_ablations.py --variants PermutedEEG,BandTheta,BandAlpha,BandBeta,LTC_param_matched --seeds 42

# 5. Mask verification, lagged analysis, channel importance
python code/verify_mask.py
python code/run_lagged.py
python code/run_channel_zeroout.py

# 6. Aggregate results, emit macros, regenerate figures
python code/summarize_results.py
python code/emit_numbers.py
python code/make_figures.py
```

Fig. 2 is rendered from `figures/Fig2_source.jpg`, the typeset architecture
diagram used in the manuscript; the remaining figures are generated from the
result registries and prediction files.

All comparisons share the same outer participant folds (seed 42), the same
inner 20% participant split for early stopping, and normalization statistics
computed on inner-training windows only. Training seeds are 42/43/44 for the
proposed model and its variants.

## Key results (exact values in `results/summary.json`)

| Model | held-out r (Δcol) |
|---|---|
| CausalEEGNet (full) | 0.221 |
| Gaze-only (same architecture) | 0.207 |
| EEG-only (same architecture) | 0.034 |
| Masked LSTM | 0.209 |
| Masked Transformer | 0.205 |
| Ridge regression (gaze history only) | 0.218 |
| Persistence (trend) | 0.015 |

Paired participant-level tests (n = 118): full vs. gaze-only Δr = −0.016
(p = 0.168); full vs. ridge Δr = −0.008 (p = 0.511); full vs. EEG-only
Δr = +0.203. Verified maximum attention on temporally prohibited positions:
0.0 for both the fixed and the learned mask.
